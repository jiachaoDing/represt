# 账号与手动同步

账号使用邮箱和密码，由分享服务中的 Better Auth 提供认证。设置 → 账号与同步支持注册、登录、手动同步和复制 AI 访问说明；核心训练功能仍可离线使用。

| 操作 | 行为 |
| --- | --- |
| 注册或登录 | 密码至少 10 字符；应用保存登录令牌，不保存密码；当前不发送邮箱验证及找回邮件 |
| 首次同步 | 上传当前设备的完整备份，范围与本地全量导出一致 |
| 后续同步 | 读取云端计划，检查本地与云端版本，上传当前设备数据并在本地接收计划修改 |
| 从云端恢复全部数据 | 换设备登录后手动选择；预览快照时间及记录数量，确认后覆盖本机全部训练数据和备份设置，计划采用云端最新版本；不上传、不合并历史 |
| 计划冲突 | 选择保留本机或采用云端的整套计划和循环日程，不逐字段自动合并 |
| 上传中断 | 在本机保留待完成操作；用户再次同步时重试同一操作 ID，成功后结清；期间新增记录可随后再次同步上传 |
| 退出 | 撤销当前会话并移除本机令牌，保留本地训练数据 |
| 复制 AI 访问说明 | 复制临时凭证和训练助手说明，引导 AI 分析记录、提供建议并保存用户要求的计划与循环调整；无需提供邮箱密码 |
| 重复复制 | 12 小时有效期内复用同一凭证，不重新签发或续期；过期或撤销后生成新凭证；无法再次读取的有效凭证保留原有效期，用户可选择继续使用已有说明或主动撤销 |
| 撤销 AI 访问 | 点击有效期旁的撤销图标，当前 AI 凭证立即失效；不会删除计划或训练数据 |
| 云端数据概览 | 应用签发 1 分钟有效、仅可兑换一次的跳转票据，新标签页自动沿用当前账号；票据位于 URL fragment，进入后立即清除；独立打开仍支持账号或临时凭证登录 |
| 导入全量文件 | 恢复原有备份数据，同时清除旧同步基线，避免把旧操作自动上传 |

```mermaid
sequenceDiagram
    participant U as 用户
    participant L as 应用
    participant S as 账号服务
    participant A as AI（支持 HTTP 工具）
    U->>L: 邮箱密码登录并点击同步
    L->>S: 上传完整快照
    U->>A: 访问说明与 12 小时临时凭证
    A->>S: 使用临时凭证读取数据与当前计划
    A->>S: 按读取版本保存计划
    U->>L: 再次点击同步
    L->>S: 检查云端计划版本
    L->>L: 有冲突时由用户选择
    L->>S: 上传新快照并结清计划改动
    L->>L: 接收计划并刷新界面
```

| 数据或权限 | 规则 |
| --- | --- |
| 本机数据库 | 版本 19 增加 `accountSync` 表，保存比较基线及待完成操作；不进入备份文件 |
| 服务地址 | 复用 `VITE_PLAN_SHARE_API_BASE_URL`；生产默认 `https://share.represt.app` |
| AI 入口 | `/api/account/guide` 提供登录方法、读取接口、计划格式、字段单位和版本规则 |
| AI 修改 | `/api/account/plans` 仅修改计划和循环日程；训练历史不会随计划调整而改写 |
| AI 权限 | 临时凭证只允许读取数据和修改计划，不能上传完整快照、生成凭证或撤销访问；服务端以摘要鉴权，另存 AES-GCM 密文用于账号本人重复复制，每次请求检查有效期 |
| 账号权限 | 邮箱密码用于应用与可视化页登录；不包含在复制的 AI 说明中；临时 AI 凭证独立于账号登录会话 |
| 训练历史 | 同步上传本机历史；云端恢复明确覆盖本机历史，不合并多设备记录。恢复前再次校验云端版本，所有表与同步基线在同一事务内更新，失败则整体回滚 |
| 容量 | 同步请求最多 10 MiB，计划写请求最多 256 KiB；超限不覆盖现有数据 |
| 隐私 | 密码、账号会话与 AI 令牌不进入 URL 或备份；跳转仅携带短期单次票据；私有响应使用 `no-store`；恢复保留当前账号会话，清除训练中的运行状态 |

前端验证：`npm test`、`npm run build`、`npm run lint`。后端资源与发布操作见 Worker 仓库中的 `ACCOUNT_SYNC.md`；前端上线前需要完成后端配置。

设置页与 AI 导入页共用账号弹层；设置项通过 `SettingsRow` 的图标、标题、副标题、右侧内容和点击回调渲染，沿用现有图标容器与行布局。
